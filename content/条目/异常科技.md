# 异常科技

> **一句话定位**：由官方机构及大型商业组织掌握的技术，领先民用领域约 **10–30 年**，但存在致命瓶颈。

---

## 一、民用基线

2020–2030 年代技术水准：智能手机、AI 辅助系统、无人机、卫星通讯、基因检测、新能源、
现代枪械、社交媒体及短视频平台。

## 二、异常科技的核心限制 ⚠️

> **关键部件高度依赖异常材料与秘境产出，无法实现工业化量产。**

这条限制是全书最重要的"防跑偏"闸门：

- 它保证世界**不会演变为纯科幻战争格局**。
- 它让 [[秘境]] 的资源价值有了正当性——不是设定爱好，是工业命脉。
- 它意味着异常装备是**稀缺品而不是消耗品**：坏一台少一台，修比换容易。

**写作纪律**：任何新设备都必须说明它的关键部件从哪来。说不出来就别加。

## 三、典型设备

| 设备 | 用途 |
|---|---|
| 异常波动探测器 | 探测异常活动 |
| [[异常监测设备]] | **预测爆发并确定范围**。材料来自最初一批秘境，是"无法量产"的最纯粹样本 |
| 认知污染过滤眼镜 | 防护认知类异常 |
| 局部记忆干涉装置 | 目击者记忆处理（见信息管控三级策略） |
| 秘境稳定锚 | 稳定秘境或延缓其与现实融合 |
| 异常材料武器 | 对规则类/实体类异常的有效手段 |
| 精神屏蔽室 | 隔离认知污染 |
| 异常生命维持仓 | 维持严重异化者生命 |

## 四、掌握者

- **官方**：[[异常署]] 及各分支机构（主要持有方）
- **商业**：[[民间势力]] 中的异常商业集团（药物、开发、安全）
  → **已知具体实例：[[伊登医药]]**（私立企业集团）。[[沈惟]] 的特制药剂即出自其渠道。
- **旧门派**：拥有不依赖工业的**传承技术**，是异常科技之外的另一条路线
- **私人渠道**：存在灰色流通。**已知实例**：[[森]] 的地下医疗／纹身手艺——
  他未必掌握异常科技，但掌握着**在异常世界里动手的能力**。

> **判断纪律**：看到一个新设备／新药剂，先问"它的关键部件从哪来"。
> 答案若是"某集团给的"，就要接着问**这个集团在这件事里图什么**——
> 在本书里，没有免费的渠道。
