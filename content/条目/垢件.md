# 垢件与记忆残留

> **一句话定位**：人类在剧烈情绪波动（死亡、背叛、极度痛苦）时，会将一部分**精神残片**附着在身边的器物上。
> 这种带有残片的旧物被称为**垢件**。

---

## 一、机制

- **附着条件**：剧烈的情绪波动——死亡、背叛、极度痛苦。
- **载体**：身边的器物。可以是任何东西，这一点很重要——垢件的可怕之处在于它可能是一只杯子。
- **对普通人的影响**：接触后感到不适、做噩梦，严重者被精神污染。

## 三、修复与代价

- **净化**：林恪通过**维修物理结构**来"缝合"或"净化"其中的精神创伤。作用于物，不作用于人。
- **共感过载**：每修复一个极具怨念的物件，他会被迫体验原主人生前最痛苦的一幕。
  - 表现：高烧、幻听、长达数天的失明、自发性假性疼痛
  - **成瘾性**：精神冲击带来短暂的吗啡般快感，使他虽痛苦却无法收手
    → 这是 [[林恪]] 全部悲剧性的发动机：他不是被迫的，他是**上瘾的**。

## 三之一、⚠️ 垢件＝「现实化石」（2026-09-22 补充，本页地位大幅提升）

> **垢件保存的并不一定只是一个人的记忆，也可能保存已经被现实覆盖或抹去的「旧版本世界」。**

### 为什么它能绕过 [[信息转译]]

| | 普通记录 | 垢件 |
|---|---|---|
| 链条 | 现实 → 观察 → 记录 → 传播 → **被当前世界重新解释** | 现实 → 个体**直接经历** → 意识状态固化 → 后人**直接读取** |
| 保存物 | 可被重写的**描述** | 某意识在特定时刻对现实的**完整主观体验** |

关键差别在**自我更新**：

- 活人的认知会不断适应当前世界
- 附着在器物上的残片**已失去完整的认知更新能力**，长期停留在**"它形成时所认为的世界"**

→ 因此垢件可以被视为：**现实化石**。
它不只保存某个人的过去，也可能保存**某一套已经消失的现实曾经存在过**。

### 由此补齐的一条历史链：人类是怎么发现秘境的

```
垢件研究（前秘境时代，官方已知记忆残片／意识状态附着）
   ↓
现代考古发现异常遗留：异常骨骼、不合体型的衣物、特殊建筑、解释不了的生活用品
   ↓ 单独看都能被解释成风俗／疾病／畸形／宗教／工艺
真正改变研究方向的是：同一地区出土的【垢件】
   ↓ 有读取能力的人在其中看到"所有人都长着兽耳兽尾，且所有人都觉得正常"
   ↓ 不同人物、家庭、年代的垢件呈现【高度一致】的异常现实结构
   ↓ 按年代整理 → 某年以前正常 → 兽化渐现 → 成熟 → 减弱 → 消失
提出假说：「历史现实偏移」（当时尚未涉及异世界）
   ↓
某地再次出现小规模 [[规则污染]] → 人与监控都说"正常"，但实验设备测出【现实偏移信号】
   ↓ 沿偏移强度向中心推进 → 发现 [[秘境入口]]
至此：历史异常 + 垢件 + 现实偏移 + 空间异常 首次被纳入同一套理论 →「秘境」概念正式形成
```

> **这条链的价值**：它把 [[垢件]] 从"[[林恪]] 的专属道具"升级为**整个世界观的认识论起点**。
> 人类不是靠看见秘境才发现秘境的，**是靠听一个死人描述他眼中的世界才发现的**。

## 五、剧情用途

- 垢件是**不需要秘境也能进入异常**的入口。对"前期偏日常"的节奏而言，这是最顺手的装置：
  一次委托、一件旧物、一场高烧，就完成了一次异常接触，不需要开副本。
- 垢件也是天然的**倒卖与销毁标的**——它是物品，就有归属、有价格、有黑市。
- 谁在制造垢件？（杀人者往往在无意中制造它们）
- **2026-09-22 新增**：垢件是唯一**能证明另一套现实存在过**的证据 →
  它是考古队、[[异常署]] 理论研究院、[[伊登医药]] 三方都会抢的东西。
  官方与集团争的不是"古董"，是**旧世界的坐标**。
