# 规则指纹与检测体系

> **一句话定位**：每成功处理一种 [[秘境]]，人类就提取一套**规则指纹**，
> 并据此造出对应的特异探针。整套体系相当于**人类文明的免疫系统**。

---

## 一、规则指纹怎么来的

处理完一种秘境后，研究机构会收集：

- 规则残留
- 污染变化数据
- 异常物质
- [[规则锚定|锚定]] 个体
- [[信息转译]] 特征

→ 汇总成这一类规则的**规则指纹** → 开发**特异性检测设备**：

| 探针类型 | 针对 |
|---|---|
| 兽化规则探针 | 兽人型污染 |
| 第二性别规则探针 | ABO 型 |
| 哨兵向导精神结构探针 | 精神规则型 |
| 特殊能量规则探针 | 能量／物理规则型 |

## 二、两套检测体系（必须同时维持）

| | 回答的问题 | 类比 |
|---|---|---|
| **泛规则检测** | 「这里有没有正在发生**未知**的现实偏移？」 | **先天免疫** |
| **特异规则检测** | 「是否与**已有规则指纹**匹配？」 | **获得性免疫** |

> **核心思路**：先问"现实是否正在被改写"，**再**问"是不是兽人污染"。
> 直接去找兽耳是错的——因为兽耳会被 [[模因污染]] 藏起来。

## 三、⚠️ 检测局限：未知规则永远测不出来

大部分特异设备只能识别**已经研究过的规则结构**。

面对一个首次出现、规则为「**死亡可以逆转**」的世界时，兽化探针可能毫无反应。

> 因此即使进入成熟阶段，秘境研究也**始终保留未知风险**。
> 这是 [[异常署]] 永远不可能彻底安全的原因。

## 四、诱发检测（最好用的一条反向手段）

思路不是观察异常内容，而是：

1. **人为制造一个污染区必须修正的现实矛盾**
2. 不直接看异常，而是观察**现实有没有发生"额外修正"**
3. 无污染 → 世界不会有特殊反应
4. 有污染 → 污染规则为维持自洽，**必须**对这个矛盾作出解释或修正
5. 由此反向确认：**该区域存在主动维持现实一致性的异常规则**

> **写作价值**：这是全书最像"科学实验"的一场戏。
> 它没有怪物、没有打斗，只有一群人在一个看起来完全正常的地方**反复制造小矛盾，然后读数**。

## 五、与 [[异常监测设备]] 的关系

| | [[异常监测设备]]（既有页） | 本页 |
|---|---|---|
| 层级 | 具体那台仪器（预测爆发用） | 仪器背后的**整套体系** |
| 手段 | 检测浓度、波频 | 现实偏移检测 + 规则指纹匹配 + 诱发检测 |
| 材料 | 最初一批秘境带出的材料 | 每次处理后的规则残留 |

⚠️ 两条设定**互补不冲突**，但"预测爆发"与"检测已存在的污染"是否为同一台设备，仍待定。见 [[_待定问题]]。
