# 半兽人

> **一句话定位**：先由生物技术造出"本世界不允许存在的身体"，再借兽人 [[规则污染|污染区]]
> 完成 [[规则锚定|现实锚定]] 的产物。
> 归类为 [[诡异]] 五类来源中的**人造异常**。

---

## 一、机制

- **手段**：非法人体实验，人与动物结合
- **产出**：半兽人——兼具人类与动物形态特征，并获得**超凡力量**
- **归属**：人造异常（由有意识行为制造的异常）
- **成功率**：**多数实验失败**

## 一之一、技术起点：兽人秘境样本（2026-09-21 补充，2026-09-22 措辞修正）

- 「人与动物结合」的实验并非凭空起步：伊登医药拿到了早期**兽人秘境**的样本（由 [[拉梅尔]] 带回），
  在此基础研发。→ 见 [[伊登医药]] [[秘境]]。
- ⚠️ **2026-09-22 修正**：他们拿到的**不是**"异世界狼人 DNA，打一针变狼人"，
  而是**很残缺的东西**——已 [[规则锚定|锚定]] 个体的组织、异常骨骼、垢件、特殊材料、经特殊设备保留的原始数据。
  研究人员**知道最后长什么样，却不知道正常人类怎么才能长成那样**——本质是**逆向工程**。
- 这把 [[半兽人]] 从「集团自研技术」改成「**秘境产物的人为复现**」——
  它的源头仍是 [[诡异]]（秘境），只是被资本接手做了工业化尝试。
- 完整流程见下一节。

## 一之二、⚠️ 改造流程重述：生物技术 + **规则锚定**（2026-09-22 已采纳的方案）

> **机构不是用秘境材料"制造兽人"，而是先用本世界的生物技术造出一个本来无法稳定存在的半兽化身体，
> 再借助兽人 [[规则污染]] 区完成「现实认证」与 [[规则锚定|锚定]]。**

这个改法保留了原有的"非法生物实验"，同时把它接进了新的规则体系。

### 完整链条

```
① 官方早期秘境研究确认某处曾出现兽人型规则污染，取得锚定个体／垢件／污染残留组织／规则数据
② [[伊登医药]] 以"医疗、生物学、污染后遗症研究"名义参与该项目 → 内部项目组【偷走数据】
   （他们因此知道某个编号污染区的位置、浓度与大概生命周期——不是公司神通广大，是站在官方成果上）
③ 十年本世界生物技术逆向工程：基因编辑、生物组织移植、神经重构、骨骼改造
   → 得到【非常不稳定的人兽嵌合体】：狼耳神经连接失败／尾椎排异／骨骼肌肉比例不兼容／
     强化嗅觉大脑处理不了／异种组织无法维持
④ 关键发现：不是技术不够，是【普通世界本身不允许这种生物结构自然成立】
⑤ 把他送入新出现的同谱系兽人污染区 → 当地规则判定"兽耳？合理。尾椎？合理。"
   → 那些不该成立的结构被重新解释为【一种正常的兽人生理形态】
⑥ 污染持续 → 逐步锚定 → 带出污染区 → 即使入口关闭，那些器官已是普通世界承认的真实结构
⑦ 为避免被规则彻底同化成标准兽人，【在锚定未完成时强行撤出】→ 一部分已锚定、一部分未完成
   → 最终形态：稳定的、但不完整的【半兽人】
```

> ✅ **这个改法一句话解决了三件事**：
> ① 保住了"科学改造"的味道；② 把 [[秘境]] 规则接了进来；
> ③ **解释了为什么是"半"兽人——不是设计目标，是抢时间抢出来的**。

## 二、为什么不能工业化（八个瓶颈叠加，缺一不可）

| 限制 | 结果 |
|---|---|
| 兽人规则 [[秘境入口]] 极少 | 实验机会非常有限 |
| 入口生命周期不可预测 | 很难安排稳定生产 |
| 人工只能**延缓**关闭，不能控制 | 无法建立永久工厂（见 [[秘境入口]] 第五节） |
| 生物改造死亡率极高 | 大部分受试者到不了锚定阶段 |
| 个体规则适配性不同 | 同样暴露：有人锚定、有人恢复、有人畸变 |
| 锚定结果无法精确控制 | 想要狼型，可能只留下感官，也可能过度兽化 |
| 多人同时暴露会增加规则扰动 | 污染扩散更快，更容易被官方侦测 |
| 每个成功个体都需要长期前期培养 | 时间、资金、实验资源极高 |

> 于是：**理论上可以制造，实际上非常不适合工业化。**
> 类似早期核工业——"科学上证明能做到"和"能够流水线生产"是两件事。

### 附加限制：规则不会机械执行人类的设计

机构设计「狼耳 + 强嗅觉 + 肌肉强化 + 保持人类认知」。
兽人规则看了一眼：**不。**——在那个世界里这些特征属于**一个完整生理系统**，
规则会把实验体往自己的"合法模板"拉，越改越会开始补：犬齿、体温、行为本能、代谢、生殖结构、感官模式。

> **人类不能把规则当成角色编辑器。**
> 这就是 [[刘成泽]] 之所以停在"半"的最后一道原因：**再晚撤出来，他就不是他了。**

## 三之一、失败实验体的去向（2026-09-20 已解决）

> **已确认：没有任何实验体离开过集团。** 失败品有两条去向，**全部由集团主动处置**：
> **流入 [[黑市]]**（"新鲜血液"／"血包"），或**回收作原材料**。

⚠️ 关键解读：**这不是泄漏，是出货**——失败品本身就是产品，一个人的失败形态是可以变现的。
（本条的完整版本与全部推演以 [[黑市]] 为**正本**，此处不重复。）

**连带影响**（仍成立，且更有力）：
集团不只制造了一个 [[刘成泽]]，它还在**持续向外界输出异常**。
这解释了 [[异常署]] 收容管理局的工作量，也解释了 [[垢件]] 之外的异常散布来源。
区别只在于——**那些异常不是泄漏的，是发货的。**

## 四、与框架的对接

- **类型归属**：人造异常，但它与**污染异化**是邻居——被改造的个体其实是在被迫适应异常规则。
- **异化率**：半兽人应该怎么算 [[异化率]]？
  按形态看，刘成泽的状态大概率已在 **50%–70%（严重异化）**区间，甚至更高。
  ✅ **确认于 2026-09-20：后来"也不算是人类"**。
  → **他在法律上已经不是人了**。这条推论的两条后果现在全部生效：
  ① 集团把他当资产有了依据；② [[温生]] 的"救"从来没有在法律上成立过——
  **他救的不是一个人，是一件他有权处置的东西。**
- **与 [[副本]] 后遗症的机制复用**：刘成泽的"人类记忆模糊 + 兽性覆盖"与副本的"人格融合、记忆混乱"是同一类现象。
  可以统一为：**人格层被外来规则覆盖**。这样全书的异常就有了一个统一的心理学模型。

## 五、叙事用途

- 半兽人是"**人造诡异**"这条线唯一被具象化的产物，它让框架里那句抽象分类变成了一个具体的人。
- 刘成泽是全书唯一一个**完全被动**的角色。谁怎么对待他，就暴露了谁是什么人。
