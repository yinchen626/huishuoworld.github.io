# 民间势力

> **一句话定位**：官方之外的六类异常力量。与 [[异常署]] 形成结构性错位，构成动态平衡。

---

## 一、六类势力

| 势力类型 | 特征 | 目标与定位 |
|---|---|---|
| **旧世家 / 门派** | 古老传承，拥有长期积累的异常知识与血脉经验 | 维护自身传承；部分与政府合作，部分保持独立 |
| **民间处理人组织** | 类似委托制事务所，处理中小型异常事件 | 承担灰色区域工作，与官方存在合作与竞争 |
| **异常商业集团** | 跨国资本进入异常领域，涵盖药物、开发、安全 | 以资本推动异常技术商业化，立场中性偏利己 |
| **觉醒派极端组织** | 人为制造异常灾害以筛选或催化能力者 | 认为异常是人类进化的必经之路 |
| **归一教派** | 宇宙恐怖倾向，相信多元宇宙终将融合 | 主动推动世界趋向异常化 |
| **自由异常者** | 无组织的独立能力者 | 状态多样——就业、直播、犯罪、研究、隐匿 |

### 已知的具体实例

| 类别 | 已有实例 |
|---|---|
| **异常商业集团** | [[伊登医药]]（私立企业集团，名称待定）。做药物，也做人体实验 |
| **民间处理人组织** | [[林恪]] 的旧物回收生意、[[森]] 的地下医疗——都是没挂牌的个体户版本 |
| **自由异常者** | 同上。这两个人严格说都属于这一类 |

> **剩下的四类（旧世家、觉醒派、归一教派，以及有组织的处理人事务所）目前全部空白。**
> 这不是问题——**日常期本来就不该看见它们**。等你写到展开期再给它们名字。


## 二、实力结构（结构性错位）

| 势力 | 优势资源 |
|---|---|
| [[异常署]]（官方） | 组织力、动员能力、法律与暴力垄断权 |
| 商业集团 | 资本、技术、渠道 |
| 旧门派 | 历史知识、异常遗产、独特传承技术 |
| 极端组织 | 行动决断力与使用禁忌手段的意愿 |

> 没有任何一方在所有维度占优，因此形成了动态平衡。
> **这条设计的好处**：主角永远能找到"某一方需要他"，也永远会被另一方盯上。

## 三、相关人物

- [[林恪]] — "旧物回收人"，没挂牌的民间处理人个体户；严格说也属自由异常者
- [[森]] — 地下医生，民间知情者；家传、残缺、道听途说的知情路径
- [[拉梅尔]] — 雇佣兵，其组织早期即接秘境委托（挂集团／官方合作线）
- [[哈迪斯]] — 拉梅尔义兄，同属义父的雇佣兵组织
- [[江晓诗]] — 原生异常个体，无组织
- 关联势力：[[伊登医药]]（异常商业集团的已知实例）· [[异常署]]（官方）

## 四、对本书当前阶段的用法（日常期）

- **民间处理人组织**：最适合承载前期日常委托——一件 [[垢件]]、一次上门维修、一个人失踪。
  [[林恪]] 的"旧物回收人"身份天然属于这个生态位（虽然他自己未必承认）。
- **自由异常者**：初期是最容易被忽略、也最容易被卷入的一群。直播、开店、摆摊的异常者——
  他们让"异常"看起来像一种职业而不是灾难。
- **觉醒派 / 归一教派**：留作后期威胁。日常期最多留一点气味（一条奇怪的招募广告）。
