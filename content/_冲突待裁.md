- [x] 🚫 **「日常期 = 两次大爆发之间的退潮期」** —— 推翻于 2026-09-20
  - 我的推演：既然是周期性爆发，那么日常期就是退潮期，公众的记忆是被稀释过的。
  - **更正记录：目前世界线还没有经历过第一次大爆发。**
  - **结论**：日常期不是"灾后"，是**灾前**。公众**没有**集体记忆可被稀释。
    日常的质感从"被维护出来的平静"变成"**真正的平静，但地基在响**"。
  - **连带影响**：[[世界概览]] 信息管控三级策略目前**只用到第一级**（事件定性）——
    三级全开是第一次大降临**之后**的事。

- [x] 🚫 **「[[拓麻透]] 记得所有琐事 = 超忆症 = 唯一能发现环境不一致的人」** —— 推翻于 2026-09-20
  - 我的推演：[[诡异]] 表现为"不一致"，而记得住细节的人是唯一能发现它的人；
    并据此推论他与 [[异常署]] 的「局部记忆处理」直接冲突。
  - **更正记录：他不是超忆症，只是对周围人的喜好比较上心。**
  - **结论**：撤回"环境警报器"与"被处理对象"两条推论。
    改为**「人的警报器」**——他记得的是人的偏好，
    而 [[异化率|异化]] 最先改变的恰恰是偏好与习惯。见 [[拓麻透]] 第六节。
  - 附带保留（已重新表述）：他依然活在记忆处理的**盲区**里——
    官方能处理"你看到了什么"，但处理不掉"**他以前不这样**"。

- [x] 🚫 **「私立学院 = 资本渗透接口 → 可接 [[伊登医药]]」** —— 推翻于 2026-09-20
  - 我的推演：私立意味着可被资本渗透，校董／资助／附属医院可接集团线。
  - **更正记录：[[晨星学院]] 与集团没有关系，不需要刻意强调。**
  - **结论**：校园线不是集团伸进日常期的手，**它就是日常期本身**。

- [x] 🚫 **「[[森]] 与 [[拉梅尔]] 起初不知道 [[诡异]] 的存在」** —— 已更正于 2026-09-22
  - 原记录：两人均属"不知情侧"（[[角色名录]] 第三节、两人页面）。
  - **更正于 2026-09-22：森和拉梅尔都是知情者。**
    - 森：父亲本就在道上、知道一些关于诡异的事；森最初没接触，是**父亲被背叛之后**才了解了一些；母亲也稍微知道一些但不深。
    - 拉梅尔：**不是不知道秘境是什么**；其雇佣兵组织**早期就已涉入秘境探索**，接受集团委托去探索隐秘／官方疏漏／合作类的秘境。
  - **连带影响**：① 两人移出不知情侧 → **不知情侧只剩校园组四人**，日常期的普通人视角全压在 [[晨星学院]]；
