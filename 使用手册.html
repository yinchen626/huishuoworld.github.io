使用手册

给人类看的。规则细节在 AGENTS.md，那是给 AI 看的。

一、这个库怎么运转

一句话：你往 raw/ 里扔素材，AI 把 wiki/ 织成一张网，你在 Obsidian 里看。

你（提供素材 + 提问 + 拍板）
        │
        ▼
   raw/  只读原料 ──►  AI 编译  ──►   wiki/  活的设定网
        ▲                                   │
        └────────── 你的新想法 ◄────────────┘

关键心态：你不是在写笔记，你是在经营一个数据库。 别自己手写 wiki/，
那样又会退化成"一堆死文件"。你的产出是素材和判断，整理是 AI 的活。

二、日常只有三条指令

场景 你只需要说
扔了新素材 「收录一下 raw/，先给我讲要点」
想问设定 「XX 和 YY 是什么关系？」「帮我推一下这条剧情线」
维护 「体检一下，看看哪里矛盾 / 缺页」

AI 会自己读 AGENTS.md、自己更新 index.md 和 log.md。

三、Obsidian 侧的一次性设置

打开 Obsidian → 打开仓库（Vault）→ 选择 E:\知识库\知识库。然后：

1. 排除工作目录（避免图谱被污染）
设置 → 文件与链接 → 排除的文件 → 添加：.workbuddy、.obsidian（.obsidian 通常已默认排除）

2. 附件统一落地到 raw/assets
设置 → 文件与链接 → 附件默认存放路径 → 选择文件夹 → raw/assets

3. 绑定「下载附件」快捷键（收录网页/画作素材时超好用）
设置 → 快捷键 → 搜 "Download" → 找到「为当前文件下载附件」→ 绑定 Ctrl+Shift+D
剪藏一篇文章后按一下，图片全部落到本地磁盘，AI 就能直接看图了。

4. 推荐插件

插件 用途
Dataview 按 frontmatter 查询页面，自动生成动态表格
Templater 一键套用 templates/ 里的模板
Web Clipper（浏览器扩展） 网页一键剪藏成 markdown 丢进 raw/参考素材/
Marp 把设定页直接变成幻灯片
Excalidraw（已装） 手绘地图、关系图，存到 raw/assets/
图谱视图（内置） 你的角色关系图——这是整个库最爽的地方

四、几个提高效率的 Dataview 查询

贴到任意笔记里即可看到动态结果。

最近更新的设定页：

```dataview
TABLE status, updated
FROM "wiki"
WHERE type != "index"
SORT updated DESC
LIMIT 20
```

还没定稿的东西（脑洞池）：

```dataview
TABLE type, tags
FROM "wiki"
WHERE status = "草稿" OR status = "存疑"
SORT updated DESC
```

所有角色一览：

```dataview
TABLE aliases AS 别名, status AS 状态
FROM "wiki/人物"
SORT file.name ASC
```

五、备份

整个库就是一堆 markdown 文件，用 git 管理即可：

cd E:/知识库/知识库
git init
git add -A
git commit -m "init: OC 知识库"

之后每完成一次收录就 commit 一次。版本历史、分支、回滚全部免费。
配合 GitHub 私有仓库就是一个自带版本控制的世界观数据库。

六、这个库怎么长大

  1. 先窄后宽。 别一上来建十个世界。先把一个主角、一个地方、一条冲突写透。
  2. 素材要真实。 raw/ 里堆得越杂，wiki/ 越有东西可提炼。
  3. 让 AI 提问。 每次收录后问它「这个设定有哪些逻辑漏洞 / 哪些地方你不敢确定」，
    它列出来的往往就是你自己没想清楚的地方。
  4. 定期体检。 每周一次「体检」，让 AI 找出孤立页和矛盾点。
  5. 规则会进化。 用着别扭就改 AGENTS.md，这份规则本身就是资产。
