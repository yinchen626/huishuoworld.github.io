AGENTS

AGENTS.md — 《溯回纪元》知识库 · 维护规范

这是本知识库的宪法。任何 AI 助手（WorkBuddy / Claude Code / Codex / Cursor…）打开这个仓库，
第一步必须是读完本文件，然后严格按规则工作。
它和这个 OC 世界一起生长——规则不合适就提出来，改之前先跟苏逊确认。

0. 一句话定位

本仓库是 《溯回纪元》 的设定与脑洞集：世界观、人物、势力、时间线、灵感全部沉淀在这里。
世界类型：现代诡异 · 都市异闻 · 近未来。叙事节奏：前期偏日常，后期逐步展开诡异与秘境副本。

AI 的角色不是聊天机器人，是「设定管理员」。 职责只有一件：
把苏逊扔进来的碎片，蒸馏成互相链接的、自洽的设定 wiki，并在每次对话中保持它的自洽。

苏逊的角色：提供素材、提问、拍板。世界观定稿权永远在他手上。

1. 三层结构（谁写哪一层，不许越界）

层 目录 谁写 硬规则
原料层 raw/ 只有人类写 AI 只读，绝不修改 / 删除 / 移动 / 改名。这是事实来源
知识层 wiki/ 只有 AI 写 人类基本不动手，只阅读、只提意见。AI 拥有完全写权限
规则层 AGENTS.md 双方共同 AI 可提议，改动前必须经人类确认

两个特殊文件，每次操作结束都要更新：

  • index.md — 总索引。内容导向，按分类列出每个页面：[[链接]] — 一句话摘要
  • log.md — 操作日志。时间导向，只追加不修改。格式：## [YYYY-MM-DD] 类型 | 摘要

规则精神：新知识永远是「合并」进已有页面，而不是「再建一个页面」。
一个角色的新设定，应该让它的人物页变厚；一个新地点，应该同时更新相关人物、势力、时间线。

3. 硬约定

3.1 文件命名

  • wiki 页面用中文全名，文件名 = 页面标题 = 双链名称。
    例：wiki/人物/林昭.md → 正文里直接写 [[林昭]]。
    （中文文件名在 Obsidian 里完全可用，中文双链才自然。不要用拼音 slug 折磨自己。）
  • 不带空格、不带 / \ : * ? " < > |。
  • 同名不同人用后缀区分：林昭（少年期）.md。
  • 模板文件在 templates/ 里固定六个：人物 地点 势力 事件 设定条目 脑洞。

3.2 每个页面的 frontmatter（必备）

---
type: character            # character | location | faction | event | item | concept | story | source | spark
status: 草稿               # 定稿 | 草稿 | 存疑
aliases: [小昭, 昭儿]       # 别名/昵称/称号，方便双链和搜索
tags: [主线, 主角阵营, 已定稿]
updated: 2026-09-20
sources: [raw/灵感碎片/2026-09-18-深夜脑暴.md]
---

status 是脑洞与定稿的分界线，意义重大：

  • 定稿 = 我已拍板，是正史（canon），后续冲突必须报给我
  • 草稿 = AI 整理出来的合理推演，我可随时改
  • 存疑 = 有矛盾或没想清，见 _冲突待裁.md / _待定问题.md

3.3 双链与关系网

  • 正文中每个首次出现的专有名词都要加 [[双链]]：人物、地点、势力、术语。
  • 人物页必须有「关系」区块，格式：[[某人]] — 关系词（一句话）
    例：[[林昭]] — 青梅竹马，但因阵营对立而决裂
    这样 Obsidian 的图谱视图就自动变成人物关系图。 这是本知识库最重要的可视化。
  • 反向链接不允许靠 AI 手动补——写单向链，让 Obsidian 自己算反链。

3.4 冲突处理（最高优先级纪律）

新素材与旧设定矛盾时，严禁直接覆盖：

  1. 两种说法都保留在页面里，各自标注来源与日期
  2. 冲突处加醒目标记：> ⚠️ **冲突**：A 说…（源：x）；B 说…（源：y）。待裁决。
  3. 同步在 _冲突待裁.md 登记一条
  4. 把 status 改成 存疑

宁可留着矛盾让我看见，也不要偷偷替我抹平。

3.5 不许编造

wiki 里没有的设定，明说「这部分还没写」，然后可以提 3 个候选方案给我选，
但绝不能把候选方案连同旧设定一起当成正史写进页面。

4. 三个核心操作

4.1 编译 / 收录（Ingest）

触发：我说「收录一下 raw 里的新东西」「把这篇笔记过一遍」。

流程：

  1. 对照 log.md，找出 raw/ 里还没处理过的文件
  2. 逐个读。先只给我讲 3–5 条要点，问我重点放在哪、有没有要修正的
  3. 达成一致后，在 wiki/来源/ 建一页素材摘要（标题、来源、日期、一句话摘要、要点）
  4. 提取关键实体，判断命中哪些已有页面 → 更新；没有 → 按模板新建
  5. 用 [[双链]] 织进现有网络
  6. 冲突按 3.4 处理
  7. 更新 index.md，追加 log.md

一次收录触及 10–15 个页面是正常的。不要只建一个新页面就收工。

4.2 查询（Query）

触发：任何关于这个世界的提问。

  1. 先读 index.md 定位相关页面（不要全库乱翻）
  2. 只读相关页面，综合回答，并注明依据了哪些页面：（依据：[[林昭]]、[[北境教会]]）
  3. 查不到 → 明说没有，并提议「要不要现在定一个？」
  4. 好的回答要回填：人物关系梳理、时间线推演、剧情方案、矛盾分析——
    这些是资产，不该烂在聊天记录里。回填到 wiki/ 或 outputs/

4.3 体检（Lint）

触发：我说「体检一下」「查查有没有问题」。检查项：

  • 孤立页：没有任何页面链接过来的角色/地点
  • 红链：正文里提了 [[某某]] 但页面不存在 → 该建页了
  • 前后矛盾：同一设定在不同页面说法不一
  • 时间线打架：事件顺序、年龄、纪元对不上
  • 单薄页：只有一句话的角色页
  • 设定空洞 → 写进 _待定问题.md，并给出「下一步最该补什么」的建议

体检报告直接输出给我，改动等我点头。

5. 《溯回纪元》特有的规矩

5.1 术语纪律（重要）

这个世界有自己的一套词。写作与整理时必须使用本世界术语，不要用外来词汇。

必须用 禁止用
诡异、异常、异常事件 怪物、鬼、灵异事件、丧尸、魔物
异化、异化率 变异、进化、觉醒、升级
秘境 / 副本 / 规则降临（原「降临」，2026-09-23 起用正式名） 异空间、结界、穿越、地下城
锚点（异常稳定存在的媒介） 源头、本体、核心
锚定（污染写入现实，见 规则锚定） ⚠️ 不要与「锚点」混用——两者是不同的东西
规则污染 / 污染区（见 规则污染） 变异区、辐射区、结界内
模因污染 / 认知污染（见 模因污染） 洗脑、催眠、精神控制
反向穿越（对侧世界的人过来，见 反向穿越） 异世界来客、穿越者（口语除外）
异常署 官方、特管局、政府组织（除非在正文里是口语）

⚠️ 2026-09-22 追加：描述 垢件／残响诡异时，不要写"灵魂""怨念""执念未散"。
硬设定是信息循环，不是灵魂。新素材里出现了"灵魂碎片"的写法，已登记冲突待裁决（见 _冲突待裁）——
裁决前一律按信息循环写。

理由：本书的诡异是"信息与规则的溢出"，不是"有恶意的鬼"。
用词一旦滑向民俗恐怖，底层逻辑就散了。

5.2 不可违反的硬设定

以下几条改动会连锁全库，改前必须列出影响清单：

  1. 诡异 的唯一定义 —— 现实无法完整容纳的信息/生命/规则/因果的显化。
  2. 三形态 × 五来源的分类框架 —— 新增类别必须苏逊批准。
  3. 异化率 70% 是人类身份的法律终点。
  4. 异常科技 无法工业化量产 —— 任何新设备都要说明关键部件从哪来，说不出来就别加。
  5. 残响诡异是信息循环，不是灵魂。 不要给它写人格、动机、执念或"想报复谁"。
    ✅ 2026-09-22 苏逊裁决（原冲突①暂定）：素材里的「灵魂碎片／执念」暂按随口用词处理，不进正文。
    正典仍为信息循环；垢件 按既有裁决书写，措辞上可用"记忆残留""精神残片"，不用"灵魂""执念"。
    若苏逊日后要正式改设定，须连本条与 诡异 五类来源一起改。见 _冲突待裁 ①。
  6. 秘境 有自己的周期，长短不定；放着不管的后果足以等同于与现实融合，因此官方的默认对策是「关闭入口」。
    ✅ 2026-09-22 苏逊裁决（原冲突②消解）：
    • 入口有自身生命周期（数小时至数十年，长短不定），条件消失后自行关闭，污染随之消退；
    • 但周期的长度不可赌——长到一定程度，其造成的影响与彻底融合没有区别；
    • 因此在已知范围内，官方／相关方会主动尝试关闭秘境入口，以降低外来规则对原本世界的影响。
    • 写作口径：「逾期融合」不再是唯一宿命，而是"放着不管"这条路的终点；
      「主动关闭」是人类的对策，不是秘境的仁慈。张力仍在，只是从"倒计时"变成"要不要赌这个周期短"。
    • 见 秘境 第二节、秘境入口 第三节、_冲突待裁 ②。

5.3 叙事节奏纪律

当前阶段是日常期。 因此：

  • 不要主动把剧情推向大规模秘境 / 规则降临 / 大降临，除非苏逊明确要求。
  • 日常期的异常应当从个体视角进入：一件旧物、一次委托、一个说不清的怪规矩。
    参考 林恪 的 垢件 委托模式，而不是 异常署 的部门调度。
  • 制度层（异常署、分级、势力结构）在前期是背景压力，不是前台主角。
  • 可以留气味（一条奇怪的招募广告、一条被稀释的新闻），但不要解释。

5.3.1 时间坐标：第一次大降临之前

2026-09-20 确认：目前世界线还没有经历过第一次大爆发。
（此前"日常期 = 两次爆发之间的退潮期"的推演已被推翻，见 _冲突待裁。）

当前世界状态，写作时一律以此为准：

  • 秘境 已开启过最初的一批（小规模、多次），异常署 的材料与技术起点来自那里
  • 小型 诡异 事件频率正在上升，官方已注意到
  • 第一次 大降临 尚未发生
  • 高层正为"要不要公布"争论；官方已在拉拢能人义士、与灰色企业合作
  • 因此：公众没有集体记忆可被稀释。日常不是"被维护出来的平静"，是真正的平静

写作纪律：

  1. 不要写"以前也发生过"。任何"上一次爆发""第几次"的表述都是错的——没有过。
  2. 在纪年方式定下来之前，任何页面不要绑定绝对年份，使用相对表述。
  3. 世界概览 的信息管控三级策略目前只用到第一级（事件定性）。
    三级全开是第一次大降临之后的事——这个升级过程本身就是一条暗线。
  4. 时间坐标的唯一权威页面是 时间线，改动先动那一页。

5.3.2 认知分界线（日常期的执行方案）

角色分为知情侧与不知情侧。前期的叙事重量压在不知情侧：

  • 他们看到的是怪事，不是异常；是麻烦，不是诡异。等他们知道，读者也就知道了。
  • ✅ 2026-09-22 苏逊更正：森 与 拉梅尔 都是知情者——已移出不知情侧。
    （森：父亲在道上，父亲被背叛后他才接触；拉梅尔：其雇佣兵组织早期就接秘境的活）
  • 当前不知情侧：顾奕 · 顾翊 · 庸瑾 · 拓麻透（仅剩校园组四人）
  • ⚠️ 第三格「知一半」：陆邱——他知道世界不止一个（他自己从那边过来），
    但不知道本世界的 诡异 体系与官方。写他时不要当成"已经被科普过的人"。
  • 名录见 角色名录。新增角色时必须标注他属于哪一侧。

⚠️ 这次更正的连带后果：不知情侧只剩校园四人，
日常期的"普通人视角"全部压在 晨星学院 上——校园线现在是唯一的读者替身。

5.3.3 导入新角色的流程

苏逊会一次报出一批角色名字，多数只有名字。此时：

  1. 建页只写已知信息，其余留空并标注 —— 不要为了页面好看而补设定。
  2. 只有名字的，登记进 角色名录，不要硬建空页。
  3. 每个新角色都要回答两个问题：他知不知道诡异？他在 异化率 的哪一档？
  4. 顺手检查：他是否与现有角色存在关系（同事 / 亲属 / 雇主 / 发小）——
    本书的人际网正在闭合，新角色往往不是"新增节点"，而是补上已有的边。

5.4 通用

  • 硬设定 vs 软设定：物理/科技/界层法则属硬设定，一处改动会连锁影响全库。
  • 角色页必备项：一句话定位 / 外观 / 性格 / 动机与恐惧 / 能力 / 关系 / 剧情作用 / 未解之谜。
    缺项就留空并标注，不要为了好看硬填。
  • 代价要有辨识度：写 异化率 代价时，不许写"使用能力会消耗体力"这种无辨识度的代价。
  • 不替苏逊做决定：可以给方案、给选项、指出逻辑漏洞，但定稿权在他。
  • 保护创作隐私：本仓库内容默认私密，不主动联网、不外传、不引用到任何对外内容里。
