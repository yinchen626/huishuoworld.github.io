秘境入口

秘境入口

一句话定位：两个原本相互独立的世界在特定条件下发生接触时，连接形成的位置。
它不只连接空间，也让双方的现实规则开始重叠 → 见 规则污染。

一、基本性质

项 内容
本质 跨入不同维度的入口——空间维度，或世界观维度（见 秘境 一之一）
单向性 通常单向：进入容易，出来受约束（既有设定）
规则效应 连接两侧的对应区域会互相渗透对方规则
关闭方式 自行关闭（条件消失）／攻略完成／人为关闭（见下）

✅ 「高维主神下派任务、完成即关闭」的玩法见 秘境 一之一（元叙事层，已裁决）。

二、链接强度（2026-09-22 新增）

素材中的比喻：两个地球挤在一起，挤得越厉害，入口的链接强度越高。

链接强度 后果
高 规则渗透更深、污染范围更大、模因污染 更强、锚定更快
低 渗透浅、范围小、可能长期无人察觉

⚠️ 待定：入口长期不关闭 → 规则持续渗透进周边区域。
渗透程度与影响范围由链接强度决定；未受训练或特殊体质的人不会意识到规则被改变。
参考：动漫《不死不幸》——只有主角团能意识到"被增加了规则"，且规则限定在入口周围区域。
→ 见 _待定问题。

三、生命周期与「主动关闭」（2026-09-22 原始记录裁决，本节重写）

入口不一定需要人为关闭，它本身有生命周期：

数小时 → 数天 → 数月 → 数年 → 数十年（不等）

条件消失后入口自行关闭 → 外来规则失去持续来源 → 本世界规则重新主导 → 污染消退（见 规则污染 第五节）。

✅ 裁定（2026-09-22）：「有长有短——但人不敢赌」

周期短的，没人记得它来过；周期长的，和融合没有区别。
所以为了降低已知范围内秘境对本世界规则的影响，会尝试关闭入口。

阶段 发生了什么
入口开启 两侧规则开始重叠 → 规则污染
周期不定 短则数小时，长则数十年——事先无人知道是哪种
不作为的后果 等它自己关；若周期长 → 实质等同彻底融合
人类的对策 主动关闭——派人进去、完成任务、破坏维持条件
  • 关闭的代价是必须有人进去（异常署 特别行动局／被雇佣的人，如 拉梅尔）。
  • 不关的代价是赌周期短，赌输的账单由污染区里的活人付（锚定者不会随入口关闭而复原，见 规则锚定）。
  • → 完整裁决见 _冲突待裁 ②；AGENTS 5.2 #6 已同步改写。

由此产生的一条极重要的历史结论：

历史上完全可能曾经出现过大量秘境，而当时的人类从始至终都不知道它们的存在。
考古发现的那些"无法解释的遗留"，就是它们留下的。见 垢件 第四节。

四、为什么"自行关闭"不构成可以不作为的理由

直觉 实际情况
反正会自己关，等就行了 等的过程里污染在累积、锚定在推进
关闭只是加速 关闭止损，不关闭则赌的是"多久算太久"
融合是另一种机制 融合 = 周期过长时不作为的实质结果，不是平行事件

一句话：入口会自己关，是世界的事；去把它关掉，是人的事。

四之一、人为延缓关闭（只能延缓，不能控制）

研究机构发现：入口关闭前会经历一段连接衰减期。通过设备维持两侧原有的共振状态，可以延后关闭。

正常 强行维持后
例 还有 3 天关闭 延长到 23 天（已是极限）

代价（五条，缺一不可）：

  1. 能源消耗巨大
  2. 设备持续损毁
  3. 污染范围不可控扩大
  4. 入口越稳定，模因污染 越强
  5. 持续时间越长，越容易被国家的现实偏移监测发现（见 异常监测设备）

于是使用者必须在「多争取一点实验时间」和「继续撑下去就会暴露」之间取舍。
这条是 伊登医药 所有实验节奏的节流阀，也是它无法量产 半兽人 的原因之一。
见 半兽人 第三节「为什么不能工业化」。

六、相关人物与关联条目

  • 拉梅尔 — 靠接活进出秘境入口的人；其组织专门探索隐秘／疏漏／合作类入口
  • 伊登医药 — 用共振设备延缓入口关闭的使用方（见本页四之一）
  • 异常署 — 主动关闭入口的执行方（特别行动局）
  • 陆邱 — 经某个短期入口落入本世界的反向穿越者
  • 关联条目：秘境 · 规则污染 · 规则降临 · 规则锚定 · 模因污染 · 异常监测设备
  • 稳定通道（官方主动转化）→ 秘境 一之二
