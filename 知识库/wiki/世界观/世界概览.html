世界概览

世界概览

整个世界的门面页。所有其他设定页最终都从这里发散出去。
改动下面任何一条硬设定前，必须先列出受影响的页面清单，并标记 ⚠️ 登记到 _冲突待裁。

一、这是个什么样的世界

  • 一句话：表面是 2020–2030 年代的近未来社会，实际运行于多层宇宙与历史可能性叠加之上；异常不是突如其来的灵异复苏，而是长期低烈度的"界层渗漏"在特定历史节点后演变为系统性社会问题的结果。
  • 类型 / 基调：现代诡异 · 都市异闻 · 近未来。前期偏日常，后期逐步展开诡异与秘境副本。
  • 与现实世界的关系：高度相似，只多了一层被官方系统性掩盖的真相。

二、硬设定（改一条会连锁全库）

  • 物理法则：世界由多层宇宙、历史可能性、意识信息叠加而成，统称 界层，层间存在天然隔离。
  • 超自然体系：唯一底层定义见 诡异——现实世界无法完整容纳的信息、生命、规则或因果，在现实层中的异常显化。
  • 统一显化链：异常源 → 锚点形成 → 界层渗漏 → 规则沉淀 → 现实显化（见 界层与异常显化）
  • 三种表现形态（表现维度，非分类）：秘境（空间型）、副本（意识型）、规则降临（规则型）
    • ⚠️ 层级纪律（2026-09-23 裁定）：规则污染 从属于 规则降临 之下，仅在 秘境入口 附近发生，不与三形态并列
  • 五种来源分类：原生异常 / 污染异化 / 残响诡异 / 越界存在 / 人造异常（见 诡异）
  • 生死与灵魂：残响诡异的本质是信息循环，不是传统意义上的灵魂。 这条直接决定了 林恪 这类能力者的行为逻辑与台词边界。
  • 代价机制：异化率。代价不是机械等价交换，而是身体适应异常规则的副作用。
  • 异常科技上限：领先民用 10–30 年，但关键部件依赖异常材料与秘境产出，无法工业化量产。此限制保证世界不会滑向纯科幻战争格局。

三、时空框架

  • 时空定位：2020–2030 年代。智能手机、AI 辅助系统、无人机、卫星通讯、基因检测、新能源、现代枪械、社交媒体与短视频平台均已存在。
  • 关键历史节点：大降临 —— 尚未发生，见下
  • 故事起始：日常期＝第一次大降临之前。
    ⚠️ 2026-09-20 更新：此前推演的"两次爆发之间的退潮期"已被推翻。
    公众从未经历过爆发级别的事件，没有集体记忆可被稀释。
  • 当前世界状态：最初的一批 秘境 已开启过；小型 诡异 事件频率正在上升；
    异常署 高层正为"要不要公布"争论，并已开始拉拢能人义士、与灰色企业合作。详见 时间线
  • 纪年方式：待定

四、社会结构

  • 官方：异常署（国家异常事务管理总署），下设八部门。
  • 民间：民间势力（旧世家门派 / 处理人组织 / 商业集团 / 觉醒派 / 归一教派 / 自由异常者）
  • 权力格局：结构性错位造成的动态平衡——官方有组织力与法律垄断权，商业集团有资本技术渠道，旧门派有历史知识与遗产，极端组织有行动决断力。不存在单一势力对所有维度的全面统治。
  • 信息管控三级策略：事件定性（伪装成工业事故 / 自然灾害 / 群体心理事件）→ 信息稀释（制造矛盾版本、水军讨论、专家分歧，不直接删帖）→ 局部记忆处理（对直接目击者选择性干预，成本高、范围受限）。
    ⚠️ 当前只用到第一级。这套策略是为"事后收拾"设计的，而目前还没有需要收拾的大事。
    → 三级全开是第一次 大降临 之后的事，这个升级过程本身就是一条暗线。

五、核心矛盾

世界观的价值不在设定多，而在于矛盾是否尖锐。这是驱动所有故事的引擎。

  1. 常态化 vs 掩盖：异常正在变成系统性社会问题，但整个社会认知系统仍按"个别事故"处理它。
  2. 官方内部路线分歧：开发派 / 封存派 / 研究派之间的策略冲突。
  3. 知情者与普通人的断裂：知道真相的人无法被相信，也不知道该不该让人相信。
  4. 异化的代价：能力越强，离人类社会越远。
